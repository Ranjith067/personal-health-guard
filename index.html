System Architecture & Modules
Module 01
Data Collection Module
Gathers healthcare data from publicly available datasets and user inputs. Collects age, BMI, blood pressure, blood sugar, heart rate, cholesterol, and lifestyle metrics.
Module 02
Data Preprocessing (MICE)
Handles missing values using Multiple Imputation by Chained Equations (MICE). Cleans, normalizes, and formats the collected data for ML processing using StandardScaler.
Module 03
Feature Selection (RFE)
Applies Genetic Algorithm–based Recursive Feature Elimination (RFE) to identify the 8 most predictive health parameters, improving model accuracy and reducing overfitting.
Module 04
ML Prediction Engine
Ensemble model combining AdaBoost, Random Forest, and Gradient Boosting with soft voting. Classifies health status into Normal, At Risk, or Critical with probability scores.
Module 05
Web Application Interface
User-friendly Flask-powered REST API backend with HTML/CSS/JS frontend. Connects user inputs to the prediction engine and displays results with actionable health advice.
Module 06
Health Record Storage
SQLite database stores all assessments with timestamps. Maintains historical health records to track trends over time and enables retrospective analysis.
